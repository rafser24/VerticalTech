Acceso al sistema

La pantalla de inicio de sesión es el punto de entrada al sistema. Solo los usuarios registrados con credenciales válidas pueden acceder. El sistema usa autenticación segura con token JWT que expira automáticamente por inactividad.

localhost:5173/login
V

VerticalTech

Sistema de Gestión Comercial

¿Problemas para acceder? Contacta al administrador

Cómo iniciar sesión

Abre el navegador y escribe la dirección del sistema (ej. http://localhost:5173).

En el campo Usuario, escribe tu correo electrónico o nombre de usuario asignado por el administrador.

En el campo Contraseña, escribe tu contraseña. Los caracteres no se muestran por seguridad.

Haz clic en el botón Iniciar sesión. El sistema te redirigirá al panel principal según tu rol.

⚠️
Si aparece el mensaje "Credenciales incorrectas", verifica que el nombre de usuario y contraseña sean exactos. El sistema distingue mayúsculas y minúsculas en la contraseña.
ℹ️
Si olvidaste tu contraseña, contacta al Administrador o Super Admin del sistema para que la restablezca desde el módulo de Usuarios.

Método de pago

Cómo realizar una venta

Haz clic en Punto de Venta en el menú lateral. El sistema cargará el catálogo de productos automáticamente.

Busca el producto usando el campo de búsqueda o filtra por categoría usando los botones de colores.

Haz clic sobre el producto para agregarlo al carrito. Cada clic adicional suma una unidad más.

Si necesitas ajustar la cantidad, usa los botones + y − que aparecen junto a cada ítem en el carrito.

(Opcional) Selecciona el cliente y el método de pago. Si no seleccionas cliente, la venta se registra como "Cliente General".

(Opcional) Aplica un descuento en el campo correspondiente.

Revisa el TOTAL y haz clic en Confirmar venta. El sistema registrará la venta y descontará el stock.

Aparecerá el ticket de venta que puedes imprimir o cerrar.

Funciones adicionales del POS

FunciónCómo accederPara qué sirve

Limpiar carritoBotón X (esquina del carrito)Vaciar todos los productos del carrito actual sin registrar venta
💡
Si un producto aparece en rojo o con número pequeño en stock, significa que está por agotarse. Crea una compra desde el módulo Compras para reponer el inventario.

Estados de una venta

EstadoSignificado
CompletadaLa venta se procesó correctamente. El stock ya fue descontado y el pago registrado.
PendienteVenta en espera (transferencia no confirmada o venta pausada en el POS).
AnuladaLa venta fue cancelada. El stock se devuelve automáticamente al inventario.

Ver el detalle de una venta

Localiza la venta en la tabla. Puedes buscar por número, cliente o estado usando la barra de búsqueda.

Haz clic en el ícono 👁 de la columna Acción.

Se abrirá un panel con el detalle completo: productos, cantidades, precios, descuentos, total y datos del cliente.

ℹ️
El historial de ventas es de solo lectura. No se pueden editar ventas pasadas para mantener la integridad del inventario y los reportes.

El módulo de Productos permite gestionar el catálogo completo del negocio: crear nuevos productos, editar información, activar o desactivar productos temporalmente y configurar alertas de stock mínimo.

🔒
Regla importante: El stock de un producto NO se puede editar directamente desde este módulo. El stock solo sube cuando registras una Compra y baja cuando registras una Venta. Esto garantiza que el historial de inventario sea siempre trazable.

Crear un nuevo producto

Haz clic en el botón + Nuevo Producto en la esquina superior derecha.

Completa el Nombre (obligatorio) y el Código (opcional — si lo dejas vacío el sistema puede generarlo automáticamente).

Escribe el Precio de venta y el Stock mínimo (umbral de alerta — no es el stock real).

Selecciona la Categoría y opcionalmente el Proveedor y la Unidad de medida.

Haz clic en Crear producto. El producto aparecerá en la lista con stock en 0. Para cargar stock, ve al módulo de Compras.

Indicadores de stock en la tabla

Color del stockSignificado
VerdeStock suficiente — por encima del stock mínimo configurado
⚠ AmarilloAlerta — stock por debajo del mínimo. Considera hacer una compra pronto
Rojo (0)Sin existencias — el producto no puede venderse hasta reabastecer

Estados de una compra

EstadoDescripción¿Actualiza stock?
BorradorCompra creada pero no confirmada. Puedes editarla o eliminarla.No
PendienteCompra confirmada y enviada al proveedor. En espera de recibir la mercancía.No
RecibidaMercancía llegó y fue verificada. El stock sube automáticamente.✅ Sí
AnuladaCompra cancelada. El stock no cambia.No

Registrar una compra

Haz clic en + Nueva Compra.

Selecciona el Proveedor de la lista desplegable.

Agrega los productos que recibiste: selecciona el producto, escribe la cantidad y el costo unitario.

Guarda la compra. Quedará en estado Borrador.

Cuando confirmes que el pedido fue enviado, cámbiala a Pendiente.

Cuando recibas físicamente la mercancía, cámbiala a Recibida. En este momento el stock de los productos se actualizará.

Haz clic en + Nuevo Usuario.
